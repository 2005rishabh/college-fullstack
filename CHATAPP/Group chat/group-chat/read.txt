### 🔹 **Project Description**

A fully functional **group chat app** that allows multiple users to chat instantly in a shared room.
Each user is assigned a random name when they connect. Messages are saved in a MongoDB database so older messages appear when new users join.

---

### 🔹 **Workflow**

1. **User connects** → assigned a random name (e.g., Alice, Bob).
2. **Old messages** (last 20) are fetched from MongoDB and shown.
3. **Socket.IO** handles:

   * `connection` — new user joins
   * `chat message` — message sent to all connected clients
   * `disconnect` — user leaves, broadcasted to everyone
4. **Messages** are saved to MongoDB with sender name and timestamp.
5. **Frontend (`index.html`)** displays:

   * Sidebar with user list and online/offline status
   * Chat area for messages
   * Input box for sending new messages

---

### 🔹 **Key Features**

* Real-time two-way communication
* MongoDB persistence (messages stored permanently)
* Online/offline user tracking
* Simple, responsive chat UI
* Auto-loading recent messages
